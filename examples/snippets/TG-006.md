## 2. Optional worked pattern: a ticket gate

```text
function gate(ticket, context):
  structural = validate_schema_and_placeholders(ticket)
  if structural.failed:
    return REVISE(structural.findings)

  results = decision_model.evaluate(
    state = { ticket, context },
    questions = {
      actionable: yes_no("Enough context to begin without guessing the goal?"),
      testable: yes_no("Acceptance criteria describe observable outcomes?"),
      contextual: yes_no("Important constraints and dependencies are present?")
    }
  )

  if results.unavailable_or_invalid:
    return ESCALATE("Semantic evaluation unavailable")

  for each required criterion:
    if results[criterion] is ambiguous:
      return ESCALATE("Review criterion: " + criterion)
    if results[criterion] fails its calibrated threshold:
      return REVISE("Fix criterion: " + criterion)

  return APPROVED_FOR_NEXT_STEP
```
