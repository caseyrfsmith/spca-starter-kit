# Use the incident-report template

Editorial draft. The template is a blank working aid, not a report of an event.

Copy templates/incident-report.md into your existing case folder, work item or review document. Replace the bracketed prompts with evidence for the case you are investigating; remove sections that do not apply rather than inventing information to fill them.

Select the simulated or real-incident label. Keep fictional evidence clearly labelled; real claims need inspectable sources. Separate observations from inferences and unanswered questions. Use existing SPCA SLP and CM identifiers only where the evidence supports them.

Keep one authoritative report with links to supporting evidence and the responsible reviewer. Record corrective actions and how you will check their outcome. Revisit the report when evidence or conclusions change. The optional investigation-exercise section is for creating a training case, not a requirement for an ordinary report.

This template has no dedicated automatic validator. The kit's ticket validator is for tickets and must not be used to validate incident reports.
